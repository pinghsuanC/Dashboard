# Favorites Page

## Overview

Add a /favorites page displaying all favorited items and collections in a compact, dev-focused list.

## Requirements

- Limit the favourites on the side bar at most 10 most recent updated favourites. Add a see all for Favourites section in the sidea bar.
- Add star icon button to TopBar linking to /favorites
- Create /favorites route with protection
- Have two sections on the page vertically, one for collections, one for items, with counts
- Fetch all user favorited items and collections
- Compact list view (VS Code/terminal style, not cards)
- Each row: type icon, title, type badge
- Click item opens ItemDrawer, click collection navigates to /collections/[slug]
- Empty state when no favorites
- Sort by most recently updated (updatedAt)


## UI Style

- Have a skeleton for when it's not loaded.
- Monospace or semi-monospace font
- Minimal padding, high density
- Subtle hover states
- No cards or heavy borders, clean lines only
