# Pagination

## Overview

Add pagination for items and collections listings with numbered page links.

## Requirements

- Create random 40 items and another 40 collections and add to the test account for testing before doing all the followings (you may or may not add relationships, doesn't matter, target is test the pagniation)
- Add pagination to /items/[type] and /collections/[slug] pages for items
- Add pagnation to /collections for collections
- Pagination controls at bottom with page numbers and prev/next links
- Disable (grey out) prev/next when not available
- Add and use constants: ITEMS_PER_PAGE = 21, COLLECTIONS_PER_PAGE = 21
- Add limit for "Recent" items for dashboard page if not yet. DASHBOARD_RECENT_ITEMS_LIMIT = 10
- Make the collection limit configuarable too while you are at it, DASHBOARD_COLLECTIONS_LIMIT = 6, 
- Do not fetch all resources at once. Only fetch the amount that a page requires
